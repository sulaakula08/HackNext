# HackNext · Ventorme

Статический лендинг для школьников и выпускников. Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4173.

- `index.html` — первый экран, три шага, тест, семь этапов поступления и открытый FAQ.
- `styles.css` — адаптивный дизайн в оригинальном стиле Ventorme: синий фон, лаймовые акценты, округлые карточки.
- `script.js` — 8 вопросов, расчёт направлений, следующие действия, возврат и скачивание результата.

Результат доступен без регистрации. Направления определяются по ответам об интересах; план учитывает страну обучения, текущую трудность, желаемый результат и срок выпуска. Равные баллы показывают несколько областей. Проценты совпадения и оценки вероятности поступления не используются.

Ответы хранятся в памяти страницы, без отправки на сервер и без сохранения после перезагрузки. Регистрация ведёт на Ventorme с `utm_source=hacknext&utm_campaign=team-175`; автоматического переноса ответов нет. Примеры на странице обозначены как иллюстрации.

Изображения и локальные файлы шрифта Onest в `assets/` взяты с исходной страницы https://ventorme.ai для сохранения визуального стиля.
