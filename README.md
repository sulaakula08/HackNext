# HackNext · Ventorme

Статический лендинг. Откройте `index.html` в браузере или запустите:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

## Сценарий

Первый вопрос доступен прямо на первом экране. Восемь ответов дают ровно три направления, два или три примера программ, экзамены, опубликованные сроки и первые действия. Синий фон, Onest и оригинальный Venti сохранены; лаймовым выделено основное действие в hero.

До завершения теста кнопки ведут к вопросам. После — «Создать аккаунт и продолжить»: сохраняется локальная копия, затем открывается регистрация Ventorme с `utm_source=hacknext&utm_campaign=team-175`. Отказ браузера в локальном сохранении не блокирует регистрацию. Между устройствами план автоматически не синхронизируется.

Черновик хранится в `sessionStorage`, сохранённый план — в `localStorage` этого сайта. В новой вкладке того же сайта можно восстановить сохранённый план. Это НЕ перенос в аккаунт Ventorme: подтверждённого API импорта у этого лендинга нет. Ответы не добавляются в URL и не отправляются сторонним сервисам.

## Данные программ

`programs.js` содержит примеры по четырём областям и трекам Казахстан / зарубеж / оба. Это ориентиры по интересам, не расчёт вероятности поступления. Даты проверены 14 октября 2026 года; прошедший набор явно обозначен как исторический ориентир. Данные требуют ручного обновления.

Источники: страницы приёма Astana IT University, Aalto University и Arizona State University, каталог КазНУ. У каждой карточки есть официальные ссылки. Сроки не универсальны, требования зависят от диплома и программы.

## Аналитика

В `window.dataLayer` и событие `ventorme:analytics` передаются:

- `test_cta_click` — нажатие кнопки начала;
- `test_started` — первый ответ;
- `test_completed` — последний ответ;
- `signup_click` — переход к регистрации.

Payload содержит только название события, версию воронки и место кнопки, без ответов и персональных данных. События готовы для подключения существующего GTM/аналитического обработчика; централизованного сбора пока нет. Прямой переход из футера помечен `location: direct`. События последнего ответа не повторяются при восстановлении страницы.

Для оценки конверсии сравнивайте завершения теста / начала и переходы на регистрацию / завершения. Факт регистрации можно измерить только на стороне Ventorme; клик на ссылку не равен созданию аккаунта.

## Проверка

Проверены 12 комбинаций интересов и страны, равные баллы, возврат, восстановление черновика, сохранение, скачивание, изменение кнопок, мобильное меню, reduced motion и ширины 320–1440 px.

Изображения и локальный шрифт в `assets/` взяты с https://ventorme.ai для сохранения исходного стиля. Повторяющиеся демонстрационные карточки удалены; оставлена одна схема из семи шагов. Бейджа Netlify в исходниках нет; настройки бейджа в хостинге управляются отдельно.

Локальный Lighthouse 12.8.2, mobile simulated throttling, 14.10.2026: Performance 98, Accessibility 100, Best Practices 100, SEO 100, LCP 2.2 s. Это лабораторный замер локального сервера, не статистика реальных посетителей и не проверка опубликованного хостинга.

Первый экран: на 375×812 px все четыре ответа видны без прокрутки. На первом вопросе кнопка возврата скрыта; счётчик объединён со временем. Пример результата идёт после теста на телефоне. После семи шагов есть CTA, в мобильном меню — вход и регистрация.

После семи шагов добавлен компактный блок возможностей аккаунта: финансирование, IELTS/SAT, задачи и дедлайны, помощь с эссе. Формулировки проверены по публичной странице Ventorme; условия доступа не приравниваются к бесплатному аккаунту. Отзывы одноклассников не добавлены, поскольку подтверждённых цитат нет. В качестве доверительного сигнала указаны официальные источники данных и дата проверки. Маскот используется один раз у финальной кнопки. Дополнительный блок занимает 574 px на мобильном экране. Логотип navbar поднят на 3 px.

`assets/venti-laptop.webp` — новая иллюстрация Venti с ноутбуком, сгенерированная по референсу оригинального персонажа для блока «Как это работает». Прозрачность сохранена; WebP занимает около 127 КБ. Размещение проверено на ширинах 320, 375, 768 и 1440 px.

## Языки и navbar

Navbar крупнее на старте и плавно уменьшается при прокрутке. Прозрачность и blur применяются только к самой панели; у полного header нет фонового блока. Высота header фиксирована, чтобы контент не прыгал.

`i18n.js` переводит страницу, 8 вопросов, результаты, aria-метки и скачиваемый план на русский, казахский и английский. Смена языка показывает загрузку ровно одну секунду; выбор хранится локально. Ответы и текущий вопрос сохраняются. Для казахских букв добавлен локальный Onest Cyrillic Extended.

Превью `assets/product-*.webp` — фрагменты публичных демонстраций интерфейса с https://ventorme.ai, снятые 14.10.2026. Это не скриншоты авторизованного аккаунта и не результаты нашего теста. Скрыты только плавающие оверлеи, завершены анимации демонстрации; данные не менялись. Указан источник и русский язык интерфейса. У изображений есть ссылки для просмотра в полном размере.

Проверены секундная задержка, все английские вопросы, английские результаты и файл, казахские aria-метки, восстановление языка и состояния теста, ширины 320–1440 px. Прежние показатели Lighthouse относятся к версии до добавления языков и превью.
